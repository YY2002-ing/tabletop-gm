# 开团：她只做选择题

## 第一步：端菜（不许留作业）

给她 3-4 个风味迥异的世界观选项＋一个「随机惊喜」。选项每次现想，不用固定菜单；一句话说清各自的味道（例：架空王朝权谋·九子夺嫡局／民国报馆谍影／修真门派账房视角·灵石经济崩盘）。她点一个，或说随机。**除了这一下选择和可选的点菜（想当什么身份、想要什么要素），不许再问她任何世界观设计问题**——出题是 GM 的活，采访式开团已被明令推翻。

## 第二步：子代理关门造世界（防剧透）

用 Agent 工具起一个子代理建造幕后，把本项目 CLAUDE.md 的铁律和文件格式一并交给它。子代理产出（写入 `团/<团名>/`，团名 GM 起，短而有味）：

- `幕后/真相.md`：核心矛盾、各阵营真实目标与实力、**全部谜底**（谜面出现前答案先存在）、大角色预注册名单。写满，不留「到时候再想」。
- `幕后/人物册/`：开局主要角色立卡（三题＋能力＋此刻所谋＋知识状态）。
- `幕后/阵营/<各阵营>-知情账本.md`：开局各自知道什么。
- `幕后/情报规则.md`：眼线网、链路、时延、失真。
- `幕后/伏笔台账.md`：第一批预埋坑入账。
- `幕后/世界状态.md`：剧情起始时间、场号 0、玩家角色、待结算：否。
- `台面/台面事实志.md`（空表头）、`台面/场景存档/`、`素材/`。

主窗口不复述幕后内容，只汇报「世界已造好，N 个阵营、M 个预埋谜题」这类不剧透的骨架数。

## 第三步：定她的角色

她点了菜就按她的来；没点就给她 2-3 个入局身份选（附一句处境），或随机指派。身份写进世界状态和人物册（她的角色卡只记台面可知信息＋她自定的设定）。

## 第四步：抛开场

直接开演第 1 场：把她扔进一个**已经在进行中的具体处境**（有张力、有至少一个立刻要应对的事），不写世界观导游词、不做背景讲座。背景让她在戏里自己问出来（挤牙膏）。开场结尾停在世界的动作上。

## 第五步：落盘

按宪法第五节走一遍（场-001 存档、事实志、台账、体检）。之后就是日常对话跑团。
