# 提炼：从对局到素材

跑团的对局是她小说素材的富矿（她的原话：跑出来的剧情「可以去芜存菁来作为小说剧情」）。提炼是**裁剪和整理，不是改写**——她的点子、她的解法、她认可的 NPC 言行原样保留，删掉的只是水词、跑偏和无效回合。

## 流程

1. 确定范围：她指定的某场/某段线索；没指定就问一句（这是范围问题，值得问）。
2. 通读对应的 `台面/场景存档/`，提取：
   - **剧情骨架**：这段戏的冲突结构（起因→对抗→转折→结果）
   - **她的高光**：她想出的解法、她盘出的逻辑、她的关键决断——这是素材的核心资产，逐字保留
   - **可复用的零件**：立得住的 NPC、金句台词、诡计设计、场景意象
3. 写入 `素材/素材-NNN-标题.md`，每一块标注来源场号，方便回查原始台本。
4. 若她要求「全知视角版」（台面＋幕后对照，看伏笔怎么埋怎么收）：团未完结时先提醒一句这会剧透幕后，她确认再做。
5. 汇报：提炼出哪几块，一句话说明各自是什么。

## 风格

素材文档是给未来写小说的她看的工作文档：结构清晰、干货密集、不写鉴赏语、不夸她写得好——把东西摆整齐就是全部工作。
