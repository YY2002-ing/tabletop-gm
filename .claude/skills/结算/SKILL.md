# 结算：镜头外的世界走一步

**铁律：幕后结算必须发生在她观测之前、写进文件，不许等她问起再现编。** 「B 为什么突然翻脸」的答案必须早就躺在回合日志里。

## 流程

1. 读 `幕后/世界状态.md` 确定本回合覆盖的剧情时间段；标记「待结算：是」。
2. **每个阵营开一个子代理，上下文物理隔离**。发给它的只有：
   - 该阵营的知情账本（它知道的全部，也是它知道的上限）
   - 该阵营在人物册/真相中的自身设定（目标、实力、行事风格）
   - 本回合的公开事件（所有人都看得见的台面变化）
   - 一句任务：「按你的利益和已知信息，决定本回合行动（含派眼线、传消息、按兵不动）。给出行动＋理由。」
   子代理**不得**看到：真相全文、其他阵营账本、伏笔台账。B 阵营不知道的，演它的代理也不知道——隔离不是假装。
3. GM 收齐各家行动，按 `幕后/情报规则.md` 裁决：
   - 行动冲突谁占先（实力、先手、地利）
   - **情报流转不许瞬移**：A 知道她见了 D，当且仅当 A 在相应位置有眼线；消息按链路延迟到账，必要时失真
4. 写 `幕后/回合日志/回合-NNN.md`：各阵营行动、裁决结果、每条情报的流向与到账时间。
5. 更新各阵营知情账本（到账的情报入账，带渠道和时间）、伏笔台账（行动埋出的新坑入账）、世界状态（时间推进、「待结算：否」）。
6. 跑 `scripts/体检.sh`。

## 呈现原则

结算本身不对她播报。后果按各自的情报链路，在**她该感知到的时刻**以世界的方式进入台面（信使、告示、异动、传闻）。她可能永远发现不了某些幕后事件——这是权谋的质感，不是浪费。
